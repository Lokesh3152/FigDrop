# ⚡ FigDrop (Local Edition) — 100% Offline & Private

This version runs completely on your local machine over \`localhost:8765\`. No external servers, no cloud tracking, 100% private.

---

## 🚀 How to Use:

### Step 1: Start the Bridge (1-Click)
Double-click \`start-figdrop.bat\` in this folder.  
*(Keep the window minimized while using FigDrop)*

### Step 2: Install Chrome Extension
1. Open Chrome and go to: \`chrome://extensions\`
2. Enable **Developer mode** (top right).
3. Click **Load unpacked** and select the \`chrome-extension\` folder inside this directory.

### Step 3: Add Widget to FigJam
1. In FigJam, press \`Shift + I\` $\rightarrow$ **Development** $\rightarrow$ **Import widget from manifest...**
2. Select the \`figjam-widget/manifest.json\` file inside this directory.
3. Click to place the widget on your canvas.

---

## 🎨 Start Capturing:
Hover over any image on the web $\rightarrow$ click **Save to FigJam** $\rightarrow$ click **Drop onto Board** in FigJam!
